# Style-only architecture references

These two source documents are retained solely to show the desired architecture-writing style:

- concise module identity;
- ranked/numbered invariants with reasons;
- simple layer map;
- checkable dependency rules;
- explicit exceptions.

They describe a BLE/connectivity SDK. **Do not import their BLE/RPC/GATT rules, namespaces, module names, or business assumptions into the Android Base Project.**
