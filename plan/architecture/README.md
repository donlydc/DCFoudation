# Architecture knowledge base

This folder is the authoritative, task-routed description of the Android Base Project architecture.

Start with [`00-index.md`](00-index.md), then read only the documents selected for the task by [`24-ai-reading-guide.md`](24-ai-reading-guide.md).

Documentation principles:

- verified reality, not wishful design;
- stable rule IDs;
- explicit invariants and dependency directions;
- small focused documents;
- known deviations are visible;
- AI should not read everything by default.
