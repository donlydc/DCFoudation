# Design System

## Contract

```text
Primitive design tokens
        ↓
Semantic theme tokens
        ↓
Reusable app components
        ↓
Feature UI
```

Feature UI should express meaning (`primary`, `error`, `surface`, `body`, `spacing.lg`) rather than brand implementation values (`Blue500`, `17.dp`, raw hex colors) when a semantic token exists.

Read only the subdocument for the concern being changed.
