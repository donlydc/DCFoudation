# Architecture knowledge base

This folder is the authoritative, task-routed description of the DC Android Foundation architecture.

Start with [`00-index.md`](00-index.md), then read only the documents selected for the task by [`24-ai-reading-guide.md`](24-ai-reading-guide.md).

Documentation principles:

- verified reality, not wishful design;
- stable rule IDs;
- explicit invariants and dependency directions;
- small focused documents;
- known deviations are visible;
- AI should not read everything by default.

This directory is being built out phase-by-phase per [`../plan/CLAUDE_IMPLEMENTATION_PLAN.md`](../plan/CLAUDE_IMPLEMENTATION_PLAN.md); progress is logged in [`../PLAN_REPORT.md`](../PLAN_REPORT.md). Documents not yet created belong to a phase that hasn't run yet — see `00-index.md` for what currently exists.
